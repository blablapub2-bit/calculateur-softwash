Calculateur Softwash.fr — projet Android Studio

Le projet embarque le calculateur HTML validé dans l'application Android via WebView.
La sauvegarde des champs utilise localStorage et DOM storage est activé pour la conserver localement sur le téléphone.

Pour compiler l'APK :
1. Installer Android Studio avec Android SDK (API 35) et un JDK compatible.
2. Ouvrir ce dossier dans Android Studio.
3. Laisser Gradle synchroniser les dépendances.
4. Menu Build > Build Bundle(s) / APK(s) > Build APK(s).

Application : fr.softwash.calculateur ; nom affiché : Calculateur Softwash.fr.
